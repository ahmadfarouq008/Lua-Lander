### 📖 About The Project
This is not a tutorial copy-paste. I am documenting my journey from zero to a playable Unity 2D game, with clean Git history, learning notes, and incremental features.

**Goal:** Build a portfolio-ready 2D game and understand core Unity architecture for a Game Dev career.

### 🛠️ Tech Stack
- **Engine:** Unity 6.5 (6000.2) - URP 2D Renderer
- **Language:** C#
- **Core Systems:** 2D Physics (Rigidbody2D), New Input System, Cinemachine, SpriteShape
- **Tools:** Git, Git LFS, GitHub

### 🧠 Key Learnings So Far

#### ✅ Part 1: Create Project [00:18:00]
- Unity 6 vs 6.1 vs 6.5 versioning & URP 2D Template
- Editor Layout, Console setup (Clear on Play, Error Pause, Collapse)
- Game View VSync & Aspect Ratio settings

#### ✅ Part 2: Unity Basics [00:30:41]
- GameObject = Container, Component = Behavior
- Transform is mandatory - position, rotation, scale
- Hierarchy, Project, Inspector, Scene vs Game View
- Lifecycle: Awake() / Start() (once) / Update() (every frame)
- Parent-Child relationships, Local vs World Position
- Focus with F key, MonoBehaviour as base class
- Debugging with Debug.Log
